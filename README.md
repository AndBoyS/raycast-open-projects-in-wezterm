# Open Projects in Herdr

A [Raycast](https://raycast.com) extension that allows you to quickly create and focus Herdr workspaces for your development projects.

For each project, the extension focuses the existing Herdr workspace when one is already open for that folder. Otherwise, it creates a new workspace with a shell pane.

## Installation

Dependencies: `Node.js`, [Herdr](https://github.com/herdrdev/herdr)

Configure the Herdr executable path in the Raycast extension preferences if `herdr` is not available on your `PATH`.

```
npm ci --production
npm run dev
```
